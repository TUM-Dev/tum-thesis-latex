  \caption[Corpus-augmentation loop of the LLM agent]{%
    Iterative corpus-augmentation loop. The distilled corpus enters the
    workspace as \texttt{corpus/}, which serves as both reference and working
    corpus; the agent is started with the initial prompt and the initial
    coverage summary. It inspects the workspace with read-only tools, writes a
    new generator script per cycle, and ends the cycle by calling
    \texttt{gain\_coverage\_report\_tool}, which executes the script, adds the
    generated seeds to \texttt{corpus/}, re-measures commit-affected coverage,
    updates the annotation, and returns a coverage delta as the sole feedback
    signal. Once the budget is exhausted, \texttt{corpus/} is the augmented
    corpus $C^{*}$.}
